# 🎵 Music Player

A simple and interactive **Music Player Web Application** built using **HTML, CSS, and JavaScript**.

The project provides a clean music-player interface where users can play audio tracks using basic music controls.

## 🚀 Features

- ▶️ Play music
- ⏸️ Pause music
- ⏮️ Previous song
- ⏭️ Next song
- 🔊 Audio controls
- 🎵 Display song information
- 🖼️ Album/cover images
- 📱 Responsive user interface
- 🎨 Clean and simple design

## 🛠️ Technologies Used

- **HTML5** – Structure of the music player
- **CSS3** – Styling, layout, and responsive design
- **JavaScript** – Music player functionality and controls
- **HTML5 Audio API** – Playing and controlling audio files

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/harishragavendra2k03/Music_Player.git
```

2. Open the project folder:

```bash
cd Music_Player
```

3. Open `Music.html` in your web browser.

4. Click the **Play** button to start listening to the music. 🎶

## 💡 How It Works

The music player uses JavaScript to control the HTML5 audio element.

Users can interact with the player using controls such as:

- **Play** – Starts the current song.
- **Pause** – Pauses the current song.
- **Previous** – Plays the previous track.
- **Next** – Plays the next track.

The audio files are stored inside the `audio` folder, while the corresponding album or cover images are stored inside the `image` folder.
